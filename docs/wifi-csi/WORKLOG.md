## 2026-10-04 11:48 KST · 입력 변환 최적화 및 중단 기록

I/Q의 JSON 생성·AST 재파싱을 숫자 배열 변환으로 교체했다. 52채널 매핑·타임스탬프·전처리 단계·CNN 입력은 유지한다. 복사 당시 입력 변환 파일과 해시는 보존하며 현재 변경 해시를 별도로 검사한다. 모델 ZIP에도 출처·변경 명세를 담고, 내보내기 실패 시 이전 ZIP을 유지한다.

Python 전체 검사 44개가 통과했다. 전처리 버튼 16조합, 표시·학습·추론 입력의 동등성과 고정 모델 점수를 확인했다. 새 합성 입력 30회 중앙값에서 I/Q 변환은 152.63→10.58ms, 전체 4초 전처리는 212.93→52.09ms였다. Windows 측정이며 실물 정확도나 Pi 성능은 미검증이다.

밤사이 60분 검사는 노트북 절전으로 연속 관찰이 끊겼다. 원자료 FAIL과 관찰 공백을 보존한다. 절전을 연속 실행 통과로 오인하지 않도록 검사 도구에 두 시계 비교와 중단 판정을 추가했으며 가짜 시계로 검증했다. 최적화 후 별도 합성 연속 검사를 수행한다. 기존 앱·개인 기록·MQTT 규격은 유지하며 Notion에는 아직 반영하지 않았다.

## 2026-10-04 01:51 KST · Windows 종료 오류

## 2026-10-04 01:40 KST · 연결 안정성과 응답 개선

카메라는 온전한 영상 프레임을 받은 뒤 연결 상태를 표시하고, 일부 바이트만 들어오는 경우에도 정지된 영상을 정상으로 유지하지 않도록 수정했다. 수신 버퍼 복사를 줄였으며 로컬 TCP 비교 결과를 검증 문서에 남겼다.

CSI 상태 조회의 복사·중복 계산을 줄이고, 손상된 메타데이터 하나 때문에 전체 목록이 열리지 않는 문제를 수정했다. 학습·모델 교체 경합과 시리얼 분할 수신도 검사했다. UI는 작은 화면의 넘침, 녹음 연타, 저장 중 뒤로가기, 늦은 요청 응답을 처리한다. 기존 엔진·전처리·MQTT 규격은 유지했다.

전체 호스트 Flutter 135개, Python 29개, 별도 체험 모드 홈 3개 검사를 통과했다. 실제 MQTT 클라이언트와 로컬 TCP 시험 브로커 검사 3개는 Flutter 합계에 포함된다. 장비 성능·행동 정확도와 별개의 소프트웨어 검사다. 합성 연속 실행과 Windows 실행파일 검증은 당시 진행 중이었으며 이후 결과는 [통합 검증 기록](UI_INTEGRATION_VALIDATION.md)에 추가했다. Notion에는 아직 반영하지 않았다.

## 2026-10-04 · 실제 장비 연결 모드

장비 주소를 앱에서 저장하는 연결 설정을 추가했다. 미설정 상태에서도 화면을 열 수 있고, 저장하면 새 주소로 연결을 적용한다. API 키는 별도 ENV 파일에 저장한다. 실제 모드에서는 모의 CSI 요청을 서비스에서 거부하고, UI도 모의 신호를 허용하는 서비스의 결과를 표시하지 않는다.

Windows 실제 모드 실행본은 체험본과 다른 폴더·포트·데이터를 사용한다. 하드웨어가 없는 상태에서 설정 저장과 연결 대기, 모의 신호 차단을 검사했다. 장비 연결 후 카메라·수어·CSI·음성의 실제 동시 운전을 확인한다. 기존 MQTT Topic/JSON은 유지한다. 자세한 결과는 [통합 검증 기록](UI_INTEGRATION_VALIDATION.md), 실행은 [실제 모드 안내](REAL_MODE.md)를 참고한다.
