# CSI 사건 변환 검사

CSI 분류 결과의 `label`과 `scores`를 기존 MQTT 사건 형식으로 바꾸는
오프라인 어댑터다. 모델 실행, USB 연결, MQTT 발행이나 장치 작동은 수행하지 않는다.

호출자는 방, 장치 ID, 낙상·정상 라벨 목록, 정상으로 복귀할 연속 결과 수를
명시해야 한다. 테스트의 라벨과 정상 결과 2회는 검사 예시이며 실사용 기준이 아니다.
현재 CSI 분류기의 라벨·새 결과 판정·복귀 기준을 검토한 뒤 실제 발행기에 연결해야 한다.

낙상 사건 하나에는 UUID, 호스트 Unix 시각, 선택한 모델 점수, 우선순위 9를 담는다.
QoS 1과 retain false로 전달하도록 봉투 정보를 만든다. 같은 사건의 낙상 결과가
반복되면 새 봉투를 만들지 않으며, 지정한 정상 결과가 연속 확인된 뒤에만 다시 생성한다.
판단 보류·잘못된 결과는 정상 연속 횟수를 끊고 진행 중 사건을 해제하지 않는다.

모델 점수는 실제 환경의 측정 정확도가 아니다. CSI `device_time`은 Unix 시각으로
사용하지 않는다. 같은 신호 구간을 반복 조회한 결과를 새로운 복귀 근거로 세면 안 된다.
사건 상태는 메모리에만 보관하며 어댑터를 다시 만들면 초기화된다.
재전송할 때는 최초 봉투의 ID를 유지해야 하고, 발행 확인·만료·재시작 정책은 별도 구현해야 한다.

저장소 루트에서 표준 라이브러리만으로 검사한다.

```sh
python3 -m unittest discover -s SW/csi_bridge -v
python3 SW/csi_bridge/export_contract_fixture.py --out SW/safehub_app/test/fixtures/csi_bridge_contract.json
```

Python 어댑터와 Flutter 수신기를 함께 검사하는 방법은
[계약 검사](CONTRACT_TEST.md)를 참고한다. 이 검사는 합성 분류 결과를 사용하며
CSI 정확도나 실제 낙상 경보 작동을 검증하지 않는다.
